# Lab3-POO
Laboratorio 3 de POO.

## Requisitos
- Visual Studio Code con soporte para Java.

## Preparación
1. Crea un directorio.
2. Descarga los archivos .java del repositorio y colocarlos directamente en el directorio.
3. Abrir Visual Studio Code.
4. Seleccionar el directorio para verlo en el entorno de desarrollo.

## Ejecución

Abre el archivo Main.java, abrir terminal y ejecutar:

    javac Main.java
    java Main.java

## Uso
Escribe el número de la operación que deseas realizar.
Para salir, selecciona 0.

Los datos se conservan únicamente mientras el programa está abierto.
